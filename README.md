# Attendance Tracker

A lightweight React application for quick and efficient classroom attendance management.

## Features

- Mark Present / Absent
- Attendance summary & percentage
- Student search
- Attendance history
- Copy attendance lists
- LocalStorage persistence
- Mobile-friendly UI

## Tech Stack

React • Vite • JavaScript • CSS • LocalStorage
